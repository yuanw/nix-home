recipe's =config.sh= exports them only to pin the value:

currently sets a seed, so behavior is unchanged either way.

- Live unblock for the build that applies the config: wrote a fixed
  =/etc/nix/nix.conf= on the Spark (removing the dead URL) and restarted
  =nix-daemon=. The next apply regenerates the file from the NixOS config.
